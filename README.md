# Hotel Management System
A Python-based console application designed to manage different hotel operations such as customers, rooms, bookings, services, billing, payments, feedback, and revenue reports.
## Features
• Add, view, and search customer details
• Add and view room details
• Add, view, and filter bookings
• Manage hotel services
• Manage buffet and activity details
• Collect and view customer feedback
• Generate customer bills
• Record payments
• Generate daily and monthly revenue reports
• Generate room occupancy reports
• Display revenue graphs using Matplotlib
• Store data using CSV files
## How It Works
The program provides a menu-driven interface where the user can select different hotel management operations.
### Main Modules
• Customer Management
• Room Management
• Booking Management
• Service Management
• Billing and Payment
• Reports
• Data Viewing
• Revenue Graphs
## Data Storage
The system uses CSV files to store information such as:
• Customers

• Bookings
• Services
• Buffet
• Activities
• Feedback
• Bills
• Payments
## Technologies Used
• Python
• CSV
• Datetime
• Matplotlib
## Requirements
• Python 3.x
• Matplotlib library
## How to Run
Run the Python file using:
`python "Hotel Management System.py"`
The program will display the main menu and allow the user to select the required operation.
